## 🖥️ Back End Servers 

### 📚 ¿Qué es un Back End Server?

Un **Back End Server** es el **hardware** y el **sistema operativo** que corre en el back-end y que aloja todos los componentes necesarios para ejecutar una aplicación web. Está ubicado en la **Data Access Layer** de la arquitectura de la aplicación.

---

### 🔧 Componentes de Software

El servidor back-end incluye tres componentes críticos:

- **Web Server**: Maneja peticiones HTTP.
    
- **Base de Datos**: Almacena y gestiona datos.
    
- **Framework de Desarrollo**: Motor principal de la aplicación.
    

Además, puede incluir:

- **Hipervisores** (para virtualización).
    
- **Contenedores** (Docker).
    
- **WAFs** (Web Application Firewalls).

---

### 🖥️ Componentes de Hardware

El hardware define la **potencia**, **rendimiento** y **estabilidad** del servidor:

- Servidores dedicados o virtualizados en **data centers**.
    
- Hosting en la **nube** para escalabilidad y alta disponibilidad.
    
- Infraestructura distribuida (varios servidores) para aplicaciones grandes.
    

---

### ⚡ Nota Clave

Las arquitecturas modernas no dependen de un solo back end server:

- **Balanceadores de carga** distribuyen tráfico.
    
- **Clusterización** mejora rendimiento y tolerancia a fallos.
    
- **Cloud Services** como AWS, Azure o GCP permiten escalar on-demand.
