## 🚀 JavaScript 

### 📚 ¿Qué es JavaScript?

**JavaScript** es uno de los lenguajes más usados en el mundo, especialmente en desarrollo **web** y **móvil**.

- **Principalmente en el front end** (navegador).
    
- **También en el back end** con tecnologías como **NodeJS**.
    
- Sin JavaScript, una web sería completamente **estática**.
    
- JavaScript **dinamiza** la web: agrega lógica, validaciones, animaciones y funcionalidades interactivas.
    

---

### 🛠️ Estructura Básica

**Código Embebido**:

```html
<script type="text/javascript">
  // Código JavaScript aquí
</script>
```

**Código Externo**:

```html
<script src="./script.js"></script>
```

🔹 **Ejemplo Básico**:

```javascript
document.getElementById("button1").innerHTML = "¡Texto Cambiado!";
```

- Cambia dinámicamente el contenido de un elemento `HTML` al que apunta el `id="button1"`.
    

---

### 🧩 Funcionalidades Comunes

JavaScript es utilizado para:

- Actualizar contenido **en tiempo real**.
    
- Procesar **entradas de usuario**.
    
- Hacer peticiones **HTTP/AJAX** al back end (sin recargar la página).
    
- Crear **animaciones** y efectos visuales junto a CSS.
    
- Mejorar la **interactividad** y **usabilidad** de una página.
    

**Ejemplo de petición AJAX**:

```javascript
fetch('https://api.example.com/data')
  .then(response => response.json())
  .then(data => console.log(data));
```

---

### ⚡️ Motores de JavaScript

Todos los navegadores modernos incluyen motores para ejecutar JavaScript en el **cliente**:

- **V8** (Google Chrome, Node.js)
    
- **SpiderMonkey** (Mozilla Firefox)
    
- **JavaScriptCore** (Safari)
    

Esto permite ejecutar código localmente **sin necesidad de volver al servidor**, mejorando tiempos de respuesta y experiencia de usuario.

---

### 🧱 Frameworks Populares

Para desarrollo moderno, usar JavaScript puro puede ser ineficiente. Se utilizan **frameworks y librerías** que aceleran el desarrollo y agregan funcionalidades:

|Framework|Descripción breve|
|:-:|:--|
|**React**|Librería enfocada en interfaces de usuario (UI).|
|**Angular**|Framework completo de front end de Google.|
|**Vue.js**|Framework progresivo para construir UIs y SPAs.|
|**jQuery**|Librería que facilita la manipulación del DOM y AJAX (aunque actualmente menos usado).|

Estos frameworks facilitan:

- **Renderizado dinámico** de contenido (Single Page Applications - SPA).
    
- **Componentización**: reuso y mantenimiento fácil.
    
- **Integración** con otras tecnologías como APIs RESTful o GraphQL.
    

---

### ⚠️ Seguridad en JavaScript

El uso incorrecto de JavaScript puede abrir puertas a vulnerabilidades como:

- **Cross-Site Scripting (XSS)**: Inyección de código malicioso.
    
- **Exposición de datos sensibles**: Variables o claves expuestas en el front end.
    
- **Manipulación del DOM** insegura.
    

Por eso:

- **Validar siempre** entradas de usuario en el back end.
    
- **Sanitizar** salidas dinámicas en el front end.
    
- **No exponer** información sensible en código JavaScript visible al cliente.
    

---

> 💡 **Conclusión**: JavaScript convierte las páginas web en aplicaciones dinámicas e interactivas. Es esencial conocerlo bien, tanto para **desarrollar** como para **auditar** aplicaciones web.
