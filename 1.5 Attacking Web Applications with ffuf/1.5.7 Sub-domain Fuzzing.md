## 🛰️ Sub-domain Fuzzing con `ffuf`

En esta sección aprendimos a usar **`ffuf`** para descubrir **subdominios ocultos** de un dominio principal, como `*.academy.htb`.

---

### 🧠 ¿Qué es un subdominio?

Un subdominio es una **extensión lógica del dominio principal**.  
Ejemplo:

- `photos.google.com` → subdominio de `google.com`.
    

---

### 🔧 Requisitos para fuzzear subdominios

Para realizar el escaneo necesitamos:

- 📄 **Wordlist de subdominios:**  
    Usamos una lista común como:
    
    ```
    /opt/useful/seclists/Discovery/DNS/subdomains-top1million-5000.txt
    ```
    
- 🌐 **Dominio objetivo:**  
    Por ejemplo: `inlanefreight.com` o `academy.htb`.
    

---

### 🚀 Comando básico para fuzzear subdominios

```bash
ffuf -w /opt/useful/seclists/Discovery/DNS/subdomains-top1million-5000.txt:FUZZ -u http://FUZZ.academy.htb/
```

Este comando intenta acceder a subdominios como `admin.academy.htb`, `dev.academy.htb`, etc.

---

### ⚠️ ¿Por qué no encontramos resultados en `academy.htb`?

Aunque usamos `/etc/hosts` para mapear `academy.htb`, **`ffuf` necesita que cada subdominio también esté en `/etc/hosts`**, ya que:

- `academy.htb` no es un dominio público.
    
- `ffuf` intenta resolver subdominios consultando DNS públicos (como `8.8.8.8`), **donde no existen**.
    

---

### ✅ Solución para fuzzear subdominios locales

Si sabes de antemano un subdominio como `admin.academy.htb`, debes añadirlo manualmente a `/etc/hosts`:

```bash
echo "SERVER_IP admin.academy.htb" | sudo tee -a /etc/hosts
```

Después podrás acceder con `http://admin.academy.htb:PORT`.
