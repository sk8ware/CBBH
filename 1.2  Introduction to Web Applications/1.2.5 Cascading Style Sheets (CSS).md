## 🎨 Cascading Style Sheets (CSS) - Resumen Técnico

### 📖 ¿Qué es CSS?

**CSS (Cascading Style Sheets)** es el lenguaje de hojas de estilo utilizado junto a HTML para definir el formato y presentación de los elementos web.

- Permite controlar el diseño: colores, fuentes, alineaciones, márgenes, etc.
    
- Mejora la experiencia visual y la usabilidad de los sitios web.
    
- Evoluciona con versiones que los navegadores van soportando progresivamente.
    

---

### 🧱 Estructura Básica de CSS

```css
body {
  background-color: black;
}

h1 {
  color: white;
  text-align: center;
}

p {
  font-family: helvetica;
  font-size: 10px;
}
```

#### 🧩 Sintaxis

- Definimos un **selector** (tag, id, class) `{ propiedad: valor; }`
    
- Se aplican **reglas de cascada** para decidir qué estilo prevalece.
    

✅ Ejemplo:

```css
#titulo { color: red; }
.parrafo { font-size: 16px; }
div > p { margin: 10px; }
```

---

### 🛠️ Uso de CSS

- **Diseño responsivo**: adapta la visualización a diferentes tamaños de pantalla.
    
- **Animaciones**: utilizando propiedades como `@keyframes`, `animation`, `transition`, etc.
    
- **Manipulación dinámica**: combinado con **JavaScript** para cambiar estilos en tiempo real.
    

✅ **Ejemplo real**:

> "Parallax Depth Cards" de Andy Merskin — demuestra cómo HTML, CSS y JS pueden combinarse para crear interfaces impresionantes.

---

### 🧰 Frameworks Populares de CSS

Para evitar escribir todos los estilos manualmente, existen **frameworks** que aceleran y estandarizan el desarrollo:

|Framework|Características Principales|
|:-:|:-:|
|Bootstrap|El más popular, facilita diseños responsivos.|
|SASS|Preprocesador que añade variables y funciones.|
|Foundation|Alternativa avanzada a Bootstrap.|
|Bulma|Basado completamente en Flexbox.|
|Pure|Minimalista, solo CSS puro.|

🔗 **Nota**: Muchos frameworks están pensados para integrarse con **JavaScript** y construir aplicaciones **full stack** modernas.

---

### 📚 CSS Más Allá del Navegador

- **XML y SVG**: CSS puede estilizar contenido basado en XML y gráficos SVG.
    
- **Mobile**: Se usa en frameworks como React Native o Flutter para definir la UI.
    

---

### 🛡️ Consideraciones de Seguridad

Aunque CSS en sí no implica riesgos directos de seguridad, combinado con JS puede ser parte de ataques más complejos (como XSS).

🔒 **Buenas prácticas**:

- Minimizar/Obfuscar los archivos `.css`.
    
- Usar Content-Security-Policy (CSP) para mitigar inyecciones de estilos o scripts.
    

---

> 💡 **CSS** es mucho más que darle color a las páginas: bien usado, es esencial para la usabilidad, accesibilidad y experiencia del usuario en aplicaciones web modernas.
