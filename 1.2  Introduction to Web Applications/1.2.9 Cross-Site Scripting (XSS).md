## 💥 Cross-Site Scripting (XSS) 

### 📚 ¿Qué es XSS?

**Cross-Site Scripting (XSS)** es una vulnerabilidad que permite **inyectar código JavaScript malicioso** en una aplicación web para que sea ejecutado en el navegador de otros usuarios.

➡️ Se basa en aprovechar entradas no validadas para **inyectar y ejecutar código** en el lado cliente (browser).

---

### 🛠️ Tipos de XSS

|Tipo|Descripción|
|---|---|
|**Reflected XSS**|El input malicioso se refleja inmediatamente en la respuesta (e.g., un mensaje de error o resultados de búsqueda).|
|**Stored XSS**|El input se guarda en el back-end (DB) y luego se muestra a otros usuarios (e.g., comentarios, posts).|
|**DOM XSS**|El input es procesado directamente en el navegador modificando el DOM, sin pasar por el servidor.|

---

### 🧩 Ejemplo práctico de DOM XSS

Código vulnerable:

```html
<script>
    function inputFunction() {
        var input = prompt("Please enter your name", "");
        if (input != null) {
            document.getElementById("output").innerHTML = "Your name is " + input;
        }
    }
</script>
```

Payload de prueba:

```html
#"><img src=/ onerror=alert(document.cookie)>
```

✅ **Resultado**: Se abre una **ventana de alerta** mostrando `document.cookie` (la cookie de la sesión del usuario).

---

### 🧠 ¿Por qué es peligroso?

- **Robo de sesiones** (cookies).
    
- **Phishing** y captura de credenciales.
    
- **Toma de control** de cuentas de usuarios.
    
- **Defacement** de sitios web.
    
- **Movimientos laterales** si se combinan con otros vectores.
    

---

### 🛡️ ¿Cómo prevenir XSS?

- **Escapar caracteres especiales** (`<`, `>`, `"`, `'`, `&`).
    
- **Sanitizar el input** del usuario: limpiar cualquier HTML o JS peligroso.
    
- **Content Security Policy (CSP)**: limitar fuentes de scripts.
    
- **Validación estricta** en **front-end** y **back-end**.
    
- Usar `textContent` en lugar de `innerHTML` siempre que sea posible.
    

---

### ⚡ Tip rápido:

Si un input no validado permite:

```html
<img src=x onerror=alert('XSS')>
```

¡Tienes un **XSS**!

---

> 💡 **Conclusión**: XSS es una de las vulnerabilidades más comunes y peligrosas. **Nunca confíes** en el input del usuario, valida y escapa siempre. 🔒
