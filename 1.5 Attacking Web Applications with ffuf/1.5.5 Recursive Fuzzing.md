## 🔁 Recursive Fuzzing con ffuf

Cuando un sitio tiene **muchos subdirectorios** y páginas anidadas, hacer fuzzing manual por cada ruta se vuelve poco práctico. Para eso existe el **fuzzing recursivo**, que automatiza el proceso.

---

### ⚙️ ¿Qué es Recursive Fuzzing?

Consiste en explorar **automáticamente subdirectorios** encontrados durante el escaneo inicial, hasta una profundidad definida. Esto permite descubrir rutas profundas como:

```
/admin/
/admin/users/
/admin/users/edit.php
```

---

### 🧪 Uso en ffuf

Para habilitarlo usamos:

```bash
-recursion
-recursion-depth 1
```

También podemos añadir:

- `-e .php` para buscar archivos PHP.
    
- `-v` para ver las URLs completas en la salida.
    

---

### 🧾 Ejemplo completo

```bash
ffuf -w /opt/useful/seclists/Discovery/Web-Content/directory-list-2.3-small.txt:FUZZ \
-u http://IP:PUERTO/FUZZ -recursion -recursion-depth 1 -e .php -v
```

Esto buscará:

- Directorios en la raíz.
    
- Subdirectorios de cada directorio encontrado.
    
- Archivos `.php` en cada nivel (según la profundidad definida).
    

---

### 📌 Resultado típico

```
http://IP:PORT/blog/           [Status: 200]
http://IP:PORT/blog/index.php  [Status: 200]
http://IP:PORT/forum/index.php [Status: 200]
```

📥 Se detectan automáticamente nuevas rutas y se agregan al escaneo. A mayor profundidad, mayor número de peticiones.

---

### 🧠 Tips

- Usa `-recursion-depth 1` para mantener el control y evitar DoS.
    
- Siempre acompaña con `-e .php` si ya sabes la extensión del sitio.
    
- Usa `-v` para tener claridad sobre las rutas descubiertas.
