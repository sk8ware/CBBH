## 🎯 Attacking Web Applications with ffuf

**ffuf (Fuzz Faster U Fool)** es una poderosa herramienta utilizada para **fuzzing de directorios, archivos, parámetros y valores** en aplicaciones web. Este módulo se enfoca en cómo sacarle el máximo provecho a ffuf para encontrar rutas ocultas, vhosts, parámetros interesantes y más.

---

### 📚 Temas Cubiertos

|💥 Técnica|📄 Descripción|
|---|---|
|🔍 **Fuzzing de Directorios**|Enumerar carpetas ocultas en el servidor web.|
|📁 **Fuzzing de Archivos y Extensiones**|Descubrir archivos sensibles como `.bak`, `.php`, `.txt`, etc.|
|🌐 **Descubrimiento de Vhosts Ocultos**|Identificar subdominios configurados en virtual hosts.|
|📌 **Fuzzing de Parámetros PHP**|Encontrar parámetros GET/POST usados por scripts PHP.|
|🔑 **Fuzzing de Valores de Parámetros**|Probar múltiples valores para ver cómo responde la aplicación.|

---

### 🧪 ¿Cómo Funciona ffuf?

La lógica detrás de `ffuf` es simple pero poderosa:

1. Usa una **wordlist** (lista de palabras clave).
    
2. Reemplaza una variable (`FUZZ`) en una URL, parámetro o cabecera.
    
3. Envía múltiples solicitudes.
    
4. Identifica resultados basados en **códigos HTTP**, **tamaños**, o **tiempos de respuesta**.
    

Ejemplo básico para buscar rutas:

```bash
ffuf -u https://target.com/FUZZ -w /usr/share/wordlists/dirb/common.txt
```

---

### 🧰 ¿Por Qué Usar ffuf?

- Súper **rápido y configurable**.
    
- Compatible con **fuzzing de headers, parámetros, cuerpos, vhosts**.
    
- Fácil de **automatizar** y combinar con otras herramientas.
    
- Ideal para **bug bounty, pentesting web y CTFs**.
