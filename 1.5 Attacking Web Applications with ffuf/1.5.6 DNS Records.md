## 🌐 DNS Records y /etc/hosts

Durante el fuzzing, encontramos una pista en `/blog/index.php` indicando que el **panel de administración fue movido a `academy.htb`**. Sin embargo, al visitar `http://academy.htb:PORT`, obtenemos un error de conexión.

---

### 🧠 ¿Por qué ocurre este error?

Los navegadores necesitan **resolver nombres de dominio (como `academy.htb`) en direcciones IP**. Para esto usan dos fuentes:

1. **Archivo local `/etc/hosts`**
    
2. **Servidores DNS públicos (como 8.8.8.8)**
    

Como `academy.htb` es un dominio **interno de HTB**, no existe en DNS públicos ni en nuestro `/etc/hosts`. Por eso falla.

---

### 🛠️ Solución

Agregar el dominio al archivo `/etc/hosts` con:

```bash
sudo sh -c 'echo "SERVER_IP academy.htb" >> /etc/hosts'
```

🔁 Reemplaza `SERVER_IP` con la IP del servidor que estás usando.

---

### ✅ Resultado

Después de esto, visitar `http://academy.htb:PORT` **funciona correctamente**. Podemos incluso acceder a rutas previas como:

```
http://academy.htb:PORT/blog/index.php
```

Esto confirma que `academy.htb` es un **alias (virtual host)** del mismo servidor.
