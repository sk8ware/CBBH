## 🛠️ Development Frameworks & APIs 

### 🌐 Frameworks de Desarrollo Web

Los frameworks permiten desarrollar aplicaciones web modernas de manera rápida y estructurada, reutilizando componentes como login, registro, formularios, etc.

|Framework|Lenguaje|Uso Común|
|:-:|:-:|---|
|**Laravel**|PHP|Startups, fácil de desarrollar.|
|**Express**|Node.js|PayPal, Yahoo, Uber.|
|**Django**|Python|Google, YouTube, Instagram.|
|**Rails**|Ruby|GitHub, Twitch, Airbnb.|

> 🔸 **Nota**: Grandes plataformas combinan varios frameworks y servidores para mejorar rendimiento y escalabilidad.

---

### 🔌 APIs en Desarrollo Web

Las **APIs** permiten la comunicación entre el **front end** y el **back end**, enviando y recibiendo datos para distintas funcionalidades.

- **API (Application Programming Interface)**: Interfaz para interactuar con aplicaciones a través de protocolos como **HTTP**.
    

### 🔹 Query Parameters

- **GET**: Datos en la URL. Ejemplo:
    
    ```
    /search.php?item=apples
    ```
    
- **POST**: Datos en el cuerpo del request:
    
    ```http
    POST /search.php
    item=apples
    ```
    

---

### 🔹 Web APIs

Existen dos grandes estándares para el diseño de APIs web:

|Estándar|Características|
|:-:|---|
|**SOAP**|Basado en XML, ideal para objetos estructurados y binarios. Ejemplo de un envelope SOAP:|

```xml
<soap:Envelope>
  <soap:Body>
    <soap:Fault>...</soap:Fault>
  </soap:Body>
</soap:Envelope>
```

| **REST** | Basado en URLs y JSON. Más simple, ideal para CRUD modular:

```json
{
  "100001": {
    "date": "01-01-2021",
    "content": "Welcome to this web application."
  }
}
```

---

### 🔹 Métodos HTTP Usados en REST APIs

|Método|Acción|
|:-:|---|
|**GET**|Obtener datos.|
|**POST**|Crear datos (no idempotente).|
|**PUT**|Crear o reemplazar datos (idempotente).|
|**DELETE**|Eliminar datos.|

---

### 📚 Comparativa SOAP vs REST

|Característica|SOAP|REST|
|:-:|:-:|:-:|
|Formato|XML|JSON (o XML)|
|Complejidad|Alta|Baja|
|Estado|Stateful|Stateless|
|Usabilidad|Integraciones complejas|CRUD simple y rápido|
|Ideal para|Servicios empresariales|APIs web/móviles|

---

### 🧠 Claves de Seguridad en APIs

- **Validar entradas**: Sanitizar user input.
    
- **Autenticación**: Tokens, OAuth.
    
- **Rate Limiting**: Evitar abusos (DoS).
    
- **HTTPS**: Cifrar la comunicación.
