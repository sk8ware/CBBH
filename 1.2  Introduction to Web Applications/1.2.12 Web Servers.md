## 🌐 Web Servers 

### 📚 ¿Qué es un Web Server?

Un **Web Server** es una aplicación que corre en el back-end server y:

- Maneja todo el tráfico **HTTP** entre el cliente (navegador) y el servidor.
    
- Responde a peticiones HTTP (HTML, JSON, binarios) y entrega páginas o recursos.
    

Generalmente operan en los puertos **80 (HTTP)** y **443 (HTTPS)**.

---

### ⚙️ Workflow de un Web Server

1. Recibe solicitudes **HTTP** del navegador.
    
2. Procesa la petición, ejecuta la lógica necesaria.
    
3. Retorna una **respuesta HTTP** con un **código de estado**.
    

|Código|Descripción|
|:-:|---|
|**200 OK**|Solicitud exitosa|
|**301 Moved Permanently**|Redirección permanente|
|**302 Found**|Redirección temporal|
|**400 Bad Request**|Sintaxis inválida|
|**401 Unauthorized**|No autenticado|
|**403 Forbidden**|Acceso denegado|
|**404 Not Found**|Recurso no encontrado|
|**500 Internal Server Error**|Error interno del servidor|
|**502 Bad Gateway**|Puerta de enlace inválida|
|**504 Gateway Timeout**|Timeout al intentar gateway|

### 🖥️ Web Servers Populares

#### Apache

- **+40%** de todos los sitios web.
    
- Open Source y multiplataforma (Linux, Windows, macOS).
    
- Integración fácil con PHP y otros lenguajes.
    
- **Usado por**: Apple, Adobe, Baidu.
    

#### NGINX

- **~30%** de todos los sitios web.
    
- Arquitectura **asíncrona** (ideal para alto tráfico).
    
- Open Source, ligero en recursos.
    
- **Usado por**: Google, Facebook, Twitter, Netflix, Cisco, HackTheBox.
    

#### IIS (Internet Information Services)

- **~15%** de todos los sitios web.
    
- Mantenido por **Microsoft**, corre en **Windows Server**.
    
- Integración nativa con **Active Directory** (Windows Auth).
    
- **Usado por**: Microsoft, Office365, Skype, Stack Overflow, Dell.
    

#### Otros Web Servers Comunes

- **Apache Tomcat**: Especializado en Java Web Applications.
    
- **Node.js**: Para aplicaciones con backend en JavaScript.
    

---

### 🔥 Notas Importantes

- Existen servidores ligeros embebidos (como Python HTTPServer).
    
- **Open Source** favorece auditoría de seguridad y flexibilidad.
    
- **NGINX** domina sitios de alto tráfico por su eficiencia y rendimiento.
