## 🗄️ Databases 

### 📚 ¿Qué es una Base de Datos?

Las **bases de datos** permiten a las aplicaciones web almacenar y recuperar:

- Contenido dinámico: publicaciones, archivos, imágenes.
    
- Información de usuario: nombres de usuario, contraseñas, datos sensibles.
    

Son esenciales para el manejo rápido y eficiente de grandes cantidades de datos.

---

### 🧩 Tipos de Bases de Datos

#### 🟦 Relacionales (SQL)

- **Estructura**: Tablas (filas y columnas) + claves primarias/foráneas → relaciones.
    
- **Modelo**: Basado en un **Esquema** (Schema).
    
- **Consultas**: SQL (Structured Query Language).
    

|Motor SQL|Descripción|
|:-:|---|
|**MySQL**|El más usado, gratuito y open-source.|
|**MSSQL**|Microsoft SQL Server, ideal para entornos Windows/IIS.|
|**Oracle**|Potente y orientado a grandes empresas (comercial).|
|**PostgreSQL**|Open-source, extensible, altamente fiable.|

> Otros: SQLite, MariaDB, Amazon Aurora, Azure SQL.

**Ejemplo de relaciones**:

- Tabla `users` (id, username, email).
    
- Tabla `posts` (id, user_id, content).
    
- Relación: `users.id = posts.user_id`.
    

#### 🟨 No Relacionales (NoSQL)

- **No** tienen tablas, ni esquemas fijos.
    
- **Modelos comunes**:
    
    - **Key-Value**: Clave-Valor (como JSON).
        
    - **Document-Based**: Documentos JSON con metadatos.
        
    - **Wide-Column**: Columnas dinámicas.
        
    - **Graph**: Relaciones como nodos y aristas.
        

|Motor NoSQL|Descripción|
|:-:|---|
|**MongoDB**|Basado en documentos JSON. Popular y escalable.|
|**ElasticSearch**|Optimizado para búsquedas rápidas en grandes datasets.|
|**Apache Cassandra**|Altamente escalable, tolerante a fallos.|

> Otros: Redis, Neo4j, CouchDB, Amazon DynamoDB.

**Ejemplo de JSON en NoSQL**:

```json
{
  "100001": {
    "date": "01-01-2021",
    "content": "Welcome to this web application."
  }
}
```

### 🔗 Integración en Aplicaciones Web

**PHP + MySQL** (Ejemplo básico):

- Conexión:
    
    ```php
    $conn = new mysqli("localhost", "user", "pass");
    ```
    
- Crear una base de datos:
    
    ```php
    $sql = "CREATE DATABASE database1";
    $conn->query($sql);
    ```
    
- Consultar usuarios:
    
    ```php
    $conn = new mysqli("localhost", "user", "pass", "database1");
    $query = "SELECT * FROM users WHERE name LIKE '%$searchInput%'";
    $result = $conn->query($query);
    
    while($row = $result->fetch_assoc()){
        echo $row["name"]."<br>";
    }
    ```
    

> ⚠️ **Advertencia**: El uso incorrecto de entradas de usuario puede exponer a **SQL Injection**. ¡Filtra y escapa siempre el input!

---

### 📌 Notas Importantes

- **SQL** es ideal para datos estructurados y consistencia.
    
- **NoSQL** es ideal para escalabilidad horizontal y datos no estructurados.
    
- El diseño de la base de datos afecta el rendimiento, seguridad y escalabilidad de la aplicación.
