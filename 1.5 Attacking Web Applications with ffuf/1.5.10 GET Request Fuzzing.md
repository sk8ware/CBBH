## 🔍 Fuzzing de Parámetros GET con ffuf

Cuando accedemos a `admin.php`, recibimos el mensaje:

```
You don't have access to read the flag.
```

Esto sugiere que puede haber un **parámetro GET** oculto que, si se proporciona correctamente, podría cambiar la lógica del backend y permitirnos ver el contenido (como un flag o panel oculto). Estos parámetros pueden actuar como claves, tokens, o indicadores de autenticación.

---

### 📘 ¿Por qué es importante?

Parámetros ocultos o no documentados:

- **No suelen ser auditados** a fondo
    
- Son una excelente superficie para vulnerabilidades como:
    
    - Acceso directo no autorizado
        
    - IDOR
        
    - LFI/RFI
        
    - Inyecciones
        

---

### 🧪 Comando para fuzzear parámetros GET

Usaremos el wordlist `burp-parameter-names.txt` de SecLists, diseñado para descubrir nombres comunes de parámetros usados por aplicaciones web.

```bash
ffuf -w /opt/useful/seclists/Discovery/Web-Content/burp-parameter-names.txt:FUZZ \
-u http://admin.academy.htb:PORT/admin/admin.php?FUZZ=key \
-fs 1234  # Cambiar '1234' por el tamaño de respuesta por defecto que devuelve "sin acceso"
```

📌 **Nota:**  
Para saber qué valor colocar en `-fs`, puedes hacer una primera petición sin parámetros y ver el tamaño del cuerpo de la respuesta (por ejemplo, con `curl -i` o desde el propio ffuf sin filtros).

---

### ✅ Ejemplo de resultado exitoso

```bash
secret       [Status: 200, Size: 876, Words: 102, Lines: 8]
```

Al visitar:

```
http://admin.academy.htb:PORT/admin/admin.php?secret=key
```

Podemos obtener un mensaje como:

```
This method is deprecated
```

Aunque no revela el flag, nos confirma que el parámetro fue **válido**, aunque su funcionalidad ha sido deshabilitada.

---

### 🚩 Siguientes pasos recomendados

1. Probar **diferentes valores** para el parámetro válido.
    
2. Cambiar `key` por otros posibles tokens o valores mágicos (`admin`, `true`, `1`, `access`, etc.).
    
3. Intentar fuzzing de **valores** para ese parámetro usando `ffuf` con el `-u` así:
    

```bash
ffuf -w wordlist_valores.txt:VAL -u "http://admin.academy.htb:PORT/admin/admin.php?secret=VAL"
```
