## 🛡️ Common Web Vulnerabilities 

Cuando no encontramos exploits públicos o realizamos pentesting a aplicaciones internas, identificar manualmente vulnerabilidades comunes es esencial. Muchas de ellas provienen de malas configuraciones o prácticas inseguras durante el desarrollo, y varias están en el **OWASP Top 10**.

---

### 🔓 Broken Authentication / Access Control

- **Broken Authentication**: Permite a atacantes evadir mecanismos de autenticación. Ejemplo: iniciar sesión sin credenciales válidas o escalar privilegios.
    
- **Broken Access Control**: Permite acceso no autorizado a funcionalidades restringidas (por ejemplo, un usuario normal accediendo al panel de admin).
    

**Ejemplo real**:

- **Vulnerabilidad**: _College Management System 1.2_
    
- **Exploit**:
    
    ```
    Email: ' or 0=0 #
    Password: cualquier valor
    ```
    

---

### 🐚 Malicious File Upload

- Permite cargar archivos maliciosos (por ejemplo, shells PHP) si no hay validación estricta de los archivos subidos.
    

**Ejemplo real**:

- **Plugin vulnerable**: _Responsive Thumbnail Slider 1.0 (WordPress)_
    
- **Técnica**: Subida de archivos con doble extensión:
    
    ```
    shell.php.jpg
    ```
    
- **Exploit disponible**: Módulo en **Metasploit**.
    

---

### 🖥️ Command Injection

- Se da cuando un input de usuario no es filtrado correctamente y permite inyectar comandos adicionales que el servidor ejecuta.
    

**Ejemplo real**:

- **Plugin vulnerable**: _Plainview Activity Monitor 20161228 (WordPress)_
    
- **Técnica**: Inyectar comandos usando el parámetro `ip`:
    
    ```
    127.0.0.1 | whoami
    ```
    

---

### 🛢️ SQL Injection (SQLi)

- Ocurre cuando el input del usuario es concatenado directamente en una consulta SQL, permitiendo manipular o extraer datos de la base de datos.
    

**Ejemplo real**:

- **Aplicación vulnerable**: _College Management System 1.2_
    
- **Código vulnerable**:
    
    ```php
    $query = "select * from users where name like '%$searchInput%'";
    ```
    
- **Ataque**: Ejecutar una consulta adicional o true statement para evadir autenticación:
    
    ```
    ' OR 1=1 --
    ```
    

---

## 🔥 ¿Por qué es importante?

- Estas vulnerabilidades son **comunes** y muchas veces **críticas**.
    
- Entenderlas te da una ventaja en cualquier entorno de ciberseguridad ofensiva.
    
- Las veremos repetidamente en pentesting real y CTFs.
    

> **🔔 Pro Tip**: ¡Cada vulnerabilidad será explicada a fondo en módulos posteriores, junto con técnicas de explotación y mitigación!
