## 🌐 Web Fuzzing 

En esta sección del módulo aprendimos a usar **ffuf** para hacer **fuzzing de directorios** y descubrir rutas ocultas en una aplicación web. Cuando un sitio no tiene enlaces visibles o no ofrece mucha información, **fuzzear** es la forma ideal de encontrar contenido útil o sensible.

---

### 🚀 ¿Qué es el Fuzzing?

El _fuzzing_ es una técnica de testing que consiste en enviar entradas (inputs) masivas, generalmente usando listas predefinidas, para observar cómo responde un servidor o aplicación. En el contexto web, esto se usa para:

- Buscar **directorios o rutas ocultas**.
    
- Identificar páginas como `/admin`, `/login`, `/config`, etc.
    
- Obtener respuestas HTTP que nos den pistas (200, 403, 401, 302...).
    

---

### 📁 Uso de Wordlists

Usamos diccionarios para automatizar las pruebas. Uno muy popular es:

```
/opt/useful/seclists/Discovery/Web-Content/directory-list-2.3-small.txt
```

Este archivo contiene nombres comunes de directorios y archivos que pueden existir en servidores web reales.

> ⚠️ Consejo: Este wordlist contiene líneas de copyright al inicio. Para ignorarlas en ffuf, usa la opción `-ic` (Ignore Comments).

---

### 💻 Comando Básico con ffuf

```bash
ffuf -w /opt/useful/seclists/Discovery/Web-Content/directory-list-2.3-small.txt -u http://IP:PORT/FUZZ -ic
```

- `-w` → Ruta del wordlist.
    
- `-u` → URL objetivo donde `FUZZ` será reemplazado por cada palabra del diccionario.
    
- `-ic` → Ignora comentarios en el wordlist.
    

---

### 📌 Ejemplo Práctico

Supón que el sitio `http://94.237.55.43:36004` no muestra nada útil al cargar. Con `ffuf` podemos descubrir si existen rutas ocultas como `/admin`, `/dashboard`, `/config`, etc.
