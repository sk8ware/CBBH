## 📁 Directory Fuzzing con ffuf

En esta parte del módulo aprendimos a usar `ffuf` para hacer **fuzzing de directorios** en aplicaciones web. Esta técnica nos permite descubrir rutas ocultas que no son visibles desde el frontend del sitio.

---

### 🛠️ ¿Qué es ffuf?

`ffuf` (_Fuzz Faster U Fool_) es una herramienta de fuzzing rápida y poderosa, especialmente útil para:

- Encontrar directorios ocultos
    
- Detectar páginas sensibles como `/admin`, `/login`, `/dashboard`
    
- Automatizar peticiones HTTP con diccionarios
    

> Ya viene preinstalado en **PwnBox**, pero puedes instalarlo con:  
> `sudo apt install ffuf -y`

---

### ⚙️ Comando básico para fuzzing de directorios

```bash
ffuf -w /opt/useful/seclists/Discovery/Web-Content/directory-list-2.3-small.txt:FUZZ -u http://IP:PUERTO/FUZZ -ic
```

- `-w` especifica el diccionario a usar (SecLists)
    
- `:FUZZ` permite usar esa keyword en la URL
    
- `-u` define la URL objetivo
    
- `-ic` ignora comentarios en el wordlist
    

---

### 🔎 ¿Qué buscamos?

El objetivo es descubrir rutas activas que devuelvan estados como:

- `200 OK` (página encontrada)
    
- `301/302` (redirecciones)
    
- `401/403` (protegidas)
    

Por ejemplo, si `http://IP:PUERTO/blog` devuelve un `301`, quiere decir que esa ruta **existe**, incluso si no muestra contenido útil a simple vista.

---

### ⚡ Rendimiento

ffuf puede lanzar **miles de solicitudes por segundo**. En el ejemplo se enviaron 87.000 peticiones en menos de 10 segundos (~9.700 req/sec).

> ⚠️ Consejo: No uses `-t 200` (200 hilos) contra sitios remotos sin autorización; puedes causar **DoS** involuntario.

---

### ✅ Resultado típico

```bash
blog                    [Status: 301, Size: 326, Words: 20, Lines: 10]
```

Indica que `/blog` existe. Aunque esté vacío, puede contener archivos ocultos que veremos en la siguiente sección (fuzzing de archivos).
