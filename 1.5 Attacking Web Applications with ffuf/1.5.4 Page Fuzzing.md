## 📄 Page Fuzzing con ffuf

Luego de descubrir directorios con `ffuf`, el siguiente paso es identificar archivos ocultos dentro de estos directorios, como páginas `.php`, `.html`, `.asp`, etc.

---

### 🔍 ¿Qué es Page Fuzzing?

Consiste en buscar **archivos con extensiones específicas** (como `index.php`, `login.asp`, etc.) dentro de rutas que ya descubrimos, como `/blog`, usando diccionarios de extensiones y nombres de archivos.

---

### 🧪 Paso 1: Fuzzear extensiones

Primero se prueba qué extensión usa el sitio, con ayuda del wordlist `web-extensions.txt`:

```bash
ffuf -w /opt/useful/seclists/Discovery/Web-Content/web-extensions.txt:FUZZ -u http://IP:PUERTO/blog/indexFUZZ
```

📌 Esto nos puede revelar que el sitio usa `.php`, por ejemplo.

---

### 🧪 Paso 2: Fuzzear páginas PHP

Una vez identificada la extensión, buscamos archivos con ese sufijo (`.php`, en este caso):

```bash
ffuf -w /opt/useful/seclists/Discovery/Web-Content/directory-list-2.3-small.txt:FUZZ -u http://IP:PUERTO/blog/FUZZ.php
```

📍 Este escaneo detecta archivos reales como:

```
index                   [Status: 200, Size: 0]
admin                   [Status: 200, Size: 465]
```

El primero indica una página vacía, mientras que el segundo puede contener un **panel de administración u otra funcionalidad crítica**.

---

### 🧠 Tip Pro

- ⚡ Usa `indexFUZZ` para encontrar extensiones.
    
- 🔐 Usa `FUZZ.php` para encontrar páginas.
    
- 🎯 Filtra por `Status: 200` para resultados exitosos.
    
- 📂 Revisa manualmente cada ruta encontrada.
